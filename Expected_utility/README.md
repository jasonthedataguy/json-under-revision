## Technical truth
- Physical book text remains canonical only after author explicitly approves the edits.
- Website is a **local preview, not a live public URL**.
- Video is an **animatic proof**, not the final TikTok/Instagram Reel/YouTube Short.
- Current artwork contains decorative fictional numbers in a notebook; these are *not* claims about actual probabilities.
- The unknown-outcome decision tree in the website/PDF is a philosophical interactive artifact, not a model that predicts someone's reaction.
- Source and illustration are not permission to use third parties' personal images or voices.
