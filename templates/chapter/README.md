# New chapter intake

1. Save the verbatim manuscript in `source/original.md` and record provenance.
2. Add the author's selected text to `source/approved.md`; record actual edits in `source/revisions.log`.
3. Set metadata, palette, artifact type and supplied artwork path in `chapter.json`.
4. Define scene crops and film beats in `production.json`; these belong to this chapter, not the shared builders.
5. Build products and inspect the PDF, crops, captions, video cuts and responsive archive.
6. Record real production state. Set `publish=true` only when this chapter is authorized for public release.

The scaffold is excluded from public builds until selected. Neither sample content nor empty products are a finished chapter.
