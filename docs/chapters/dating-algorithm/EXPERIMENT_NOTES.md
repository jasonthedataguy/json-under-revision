# Data provenance — Tinder anecdote

Source Version B describes an observational exercise with five male and five female friends and subjective profile visual scores. The source DOCX contains an **unfilled** table for 10 profiles. No observations can be inferred from the prose.

M1–M5 and F1–F5 are anonymized labels, **not real measurements**. See `DATA_TEMPLATE_BLANK.csv`. Fields for right swipes, matches and conversations remain blank.

Before authorizing publishing results, determine if the exercise actually occurred, observation window, app exposure/selectivity confounders, who rated profiles, and whether all participants gave consent. Even a complete N=10 sample would not support population-level conclusions. Scores represent a particular presentation of a profile, not a person's value.

The professor's five-by-five illustrative matching problem is **not** the user's Tinder observation, and matching by the same ranks by itself is **not a formal Nash equilibrium** without payoff and deviation analysis.
